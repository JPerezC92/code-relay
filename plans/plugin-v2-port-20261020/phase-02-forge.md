## Abort conditions

- Halt if `T1` has not returned `COMPLETED` with an accepted content identity, or if its port contract changed after acceptance. Report `BLOCKED` with the observed predecessor state and the invalidated identity.
- Halt if `await gateway.listen()` fails during `setup` because the gateway port is unavailable. Report `BLOCKED` with the observed bind error, the port in question from `detectEndpoints()`, and bounded options (fail plugin load with a clear error, or defer listening to first use) with a recommended default. Never swallow a bind failure inside `setup`.
- Halt if the V2 `ctx` surface cannot express one of the preserved behaviours — first-call-only secret delivery, subscription abort on cleanup, or the child-root event filter. Report `BLOCKED` with the missing capability, the documentation consulted, and bounded options.
- Halt if the V2 `Tool.Result` shape cannot carry the `output` payload unchanged, or if `metadata` cannot hold the former `title` value. Report `BLOCKED` with the observed type error, the `tool.d.ts` line consulted, and bounded options (drop `title` entirely and record the loss, or carry it in `metadata`). Never return a `title` field on a V2 `Result`, and never widen `output` to compensate.
- Halt if preserving the `coderelay_pair` name, description or result shape would require changing `gateway.ts` or `packages/protocol/**`, both outside this footprint. Report `BLOCKED` with the exact conflict.
- Stop before any out-of-assignment write/mutation or incompatible access; report `BLOCKED` to the parent. Missing current inputs/capacity/isolation or stale evidence blocks readiness, not permission to improvise.
