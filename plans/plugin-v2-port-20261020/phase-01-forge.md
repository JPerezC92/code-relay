- Halt if the V2 operation surface cannot express one of the current permitted host actions one-to-one. Report `BLOCKED` with the missing action, the V2 documentation consulted, and the bounded options (narrow the permitted set with user approval, or map to a documented composite) and a recommended default. Do not silently drop or widen a permitted action.
- Halt if preserving the exported signatures of `executeAllowedAction` / `projectActivityPart` would require editing `gateway.ts`, since `gateway.ts` is outside this phase's write footprint. Report `BLOCKED` with the exact signature conflict and bounded options.
- Halt if `pnpm install` changes any dependency outside `packages/opencode-plugin`'s manifest in a way that affects `packages/protocol` or `apps/mobile`. Report `BLOCKED` with the observed resolution diff.
- Halt if a test assertion cannot be preserved because the V2 surface changes observable behaviour. Report `BLOCKED` with the assertion, the behaviour delta, and bounded options; never rewrite an assertion to match weaker behaviour without reporting.
- Stop before any out-of-assignment write/mutation or incompatible access; report `BLOCKED` to the parent. Missing current inputs/capacity/isolation or stale evidence blocks readiness, not permission to improvise.
